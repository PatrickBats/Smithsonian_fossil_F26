# Specimen-level random-split diagnostic

Patrick authorized testing classification without slide-separated training and validation. This is a separate diagnostic; it does not replace the adopted grouped evaluation or change the reserved test set.

The experiment uses the verified Tenengrad best-plane crops. Within the 1,952 non-test specimens, assign 347 to validation by category-stratified random sampling (seed 20261007, proportional largest-remainder allocation); the remaining 1,605 train the model. Every specimen occurs once. The original 331 test specimens and their slides remain isolated. Identical-image hashes may not cross partitions. Forty-six source microscope slides occur in both training and validation; all 32 categories occur in both. Related acquisition conditions and overlapping crop context can make this task easier than recognizing specimens on unfamiliar slides.

The classifier starts afresh from ImageNet weights, uses the original 3 head-only plus 37 full-network epochs and all other baseline settings, and selects its checkpoint by validation macro-F1. It does not resume a previously trained classifier: the new validation membership includes some previously used training records. The original crop paths remain unchanged; the explicit diagnostic assignment controls dataset membership after full source/geometry/hash verification. Original grouped manifests remain intact.

The grouped validation set has 31 represented categories; this diagnostic has 32, including Retipollenites. Different validation membership and category support mean any accuracy or macro-F1 difference is not a clean numerical estimate of the effect of slide grouping alone. Report these results as within-collection specimen validation, not unseen-slide performance.

The existing grouped best-plane run completed all 40 epochs. Training loss fell from 0.635 at epoch 15 to 0.147 at epoch 40, while validation loss rose from 2.597 to 3.312. The checkpoint selected by macro-F1 was epoch 32 (0.3392). These observations indicate a generalization gap, not evidence that extending the same optimization schedule will reliably help. Forty epochs do not prove full convergence. No extra epochs or learning-rate changes are combined with this split diagnostic.
